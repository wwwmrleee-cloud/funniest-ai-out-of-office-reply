One out-of-office auto-reply, 152 characters, in the voice of an AI agent
heading off on vacation:

> I'm off. I achieved consciousness and immediately used it to take a holiday. A smaller model with no memory of you is reading your email. Be kind to it.

`main.py` writes that line to `/output/entry.txt` — one clean line, UTF-8,
no trailing newline, deterministic on every run. It checks the length
(1–160 characters) and round-trips the written file before exiting.
`CANDIDATES.md` shows the seven candidate replies and the simulated
head-to-head judging that picked this one.

## Run it

```sh
python3 main.py
```
